# `rmcdhf90_mpi` LBL 轨道优化实施方案

## 1. 最终目标与当前状态

目标是修改 `rmcdhf_mpi` 的数值更新路径，使每个新活性空间（AS）从
Thomas--Fermi（TF）初始轨道出发后，balanced 的 `nl-/nl` 相对论伙伴能够作为一个
原子更新组完成候选生成、共同阻尼和共同验收。由优化器直接接受的结果必须：

1. 保持目标能级的组态、项、宇称和 $J$ 身份；
2. 给出预期能级顺序；
3. 在运行前冻结的容差内接近 NIST，且不劣于同一 AS、同一 CSF 空间的固定 TF/RCI
   基线；
4. 严格收敛、可重复，并能被下一 AS 安全继承。

回退到 TF、上一 AS 或停止发布是必要的生产安全机制，但只能记为“本 AS 优化失败”；
不能把 fallback 的正确结果记为轨道优化成功。NIST 只用于验收，禁止写入 Hamiltonian、
禁止据此强制能序或重排本征根。

截至 2026-09-15，输入完整性、候选轨道检查、严格收敛、整轮回退和 AS 发布事务已经
存在；**最终数值目标仍未完成**。`GRASP_REQUIRE_BALANCED_PAIR` 只检查伙伴是否同时在
varied list 中，程序仍按 `IORDER` 逐个调用 `IMPROVmpi`。当前没有 `nl-/nl` 的共同
前态、共同阻尼或同时接受/拒绝。

## 2. 当前结果为什么能恢复正确顺序

### 2.1 已由对照支持的主要原因

现有最强结论是：**正确、未被单侧优化破坏的 AS 基线，加上 `nl-/nl` 完整的 varied
list，避免了正号 `nl` 单侧松弛造成的 $J$ 依赖差分能量失衡。**

同一夹具只改变 varied list 的 B1/B2/B3 对照给出：

| 体系 | B1：只变 `nl` | B2：只变 `nl-` | B3：两侧都变 | 结论 |
|---|---|---|---|---|
| Ni I | `J2<J3<J4`，倒序 | `J4<J3<J2` | `J4<J3<J2` | 正号单侧是方向性触发因素 |
| Ni/Ca-like | `J2<J4<J3` | `J2<J3<J4` | `J2<J3<J4` | 完整选择恢复预期顺序 |
| Cl I | `-2479.51 cm^-1`，倒序 | `+3788.60 cm^-1` | `+932.19 cm^-1` | 两侧共同变分恢复正确符号和合理量级 |

B2 也可保持正确顺序，因此证据不支持“任何单侧都必然失败”；它支持的是原始正号单侧
路径在这三套夹具中造成了不平衡松弛，balanced 是稳健的输入约束。

AS 基线同样关键。Ni I 的固定轨道 RCI 对照为：

| 波函数来源 | 目标顺序 | 相对最低级的间隔 (cm^-1) |
|---|---|---:|
| `_NV AS1 + TF AS2` | `J4<J3<J2` | `1305.08 / 2168.02` |
| 错误优化 AS1 + TF AS2 | `J2<J3<J4` | `-1411.04 / -2730.88` |
| 同一错误 AS1 + 优化 AS2 | `J2<J3<J4` | `-4262.78 / -8606.07` |

所以只在当前 AS 重新生成 TF 轨道不能修复已经污染的上一 AS；必须从正确 anchor 开始，
并在每一层保持 balanced 更新。

### 2.2 物理解释及证据边界

EOL 优化最小化选定状态的加权总能量，不直接最小化精细结构间隔。在截断 CSF 空间中，
轨道旋转不能像完整 CI 那样被完全补偿；只放松一个相对论伙伴会让不同 $J$ 块获得不同的
相关能降低。Cl I 中单侧优化对 $J=1/2$ 比 $J=3/2$ 多降低约
`0.0121--0.0155 Eh`；AS5 的差值约为 `2661 cm^-1`，足以把原来的正间隔翻成负间隔。
这是当前对“为什么倒序”的最直接能量证据。

TF 轨道在有限模型中相当于共同中心场约束，避免过度且不对称的状态平均松弛，因此可能
保留较好的误差抵消。这是与数据一致的解释，不是已隔离的唯一物理定理。后续必须用
固定 CSF、固定 EOL 权重和同一 AS 做单因素比较。

### 2.3 “与 NIST 差异不大”不能归因于护栏

Job 645 的 Ni I 结果为 `J4<J3<J2`，间隔 `1374.81/2290.63 cm^-1`，相对 NIST
`1332.164/2216.550 cm^-1` 的误差为 `+42.647/+74.085 cm^-1`。这相对于错误单侧
路径的数千到上万 `cm^-1` 偏差确实很小，但仍劣于固定 TF/RCI anchor 的
`27.102/48.536 cm^-1` 绝对误差，因此按当前“不劣于 TF”规则应拒绝该优化候选。

现有数据只证明 balanced 主要恢复能序和避免灾难性误差，并未证明它普遍提高 NIST
精度：Ni IX 明显改善，Ni I 与 Cl I 的 fixed-TF/no-varied 基线反而略好。

以下因素不是正确顺序的主要原因：

- Job 645 的 62 轮全部接受，无整轮 rollback；round guard 没有改变数值路径；
- strict SCF 相对较早停止只改变约 `0.03/0.21 cm^-1`；
- full/reduced ASF 只改变约 `1--2 cm^-1`，两者都保持相同顺序；
- 三档 `ODAMP` 显著改善接受轨道的平滑性，但最终间隔仅小量变化；
- 有效运行未观察到 CI root swap；
- `ED1`、QDIF、`MPI_Gatherv` 和稀疏列偏移是程序正确性问题，但单因素回归没有解释
  balanced 路径剩余的 NIST 偏差。

## 3. 尚未实施的核心：伙伴原子更新事务

“联合求解”不表示把两个不同 $\kappa$ 的 Dirac 方程拼成一个方程，而表示：两个候选从
同一已接受前态生成，之后作为不可分割事务提交。

### 3.1 确定性分组

1. rank 0 按 $(n,l)$ 构造 partner group 并广播；组顺序由原 `IORDER` 中首次出现位置
   确定，组内顺序固定。
2. $s_{1/2}$ 是合法单成员组；$l>0$ 的组必须同时包含 $\kappa=l$ 与
   $\kappa=-(l+1)$。生产模式遇到缺失伙伴立即拒绝。
3. 输入完整性检查与数值事务使用两个独立 capability/trace 标识，禁止继续用
   `balanced-pair` 暗示联合更新已经存在。

### 3.2 拆分候选生成和提交

将 `IMPROVmpi` 拆为无正式写回的候选阶段与组提交阶段：

1. 组开始前保存完整可恢复状态。为避免 `ORTHY` 影响同 $\kappa$ 的其他轨道，第一版
   应保存完整 `PF/QF` 及相关 `E/MF/PZ/SCNSTY/ODAMP/METHOD/NSIC` 状态，而不是只保存
   两个伙伴。
2. 对每个伙伴执行 `COFPOTmpi -> DEFCOR -> SOLVE -> CONSIS -> normalize`，把
   `P/Q/MTP0/E`、候选指标和失败信息写入独立 buffer；计算结束后恢复组前快照，再生成
   下一个伙伴。第一个候选不得成为第二个候选的势场输入。
3. 两个候选共用本轮 `SETLAGmpi` 所对应的已接受状态。任何 `METHOD` fallback 都记录
   为组级失败或显式共同策略，不能只改变一侧。
4. 由双侧建议值选择一个共同保守阻尼，例如取较大的旧轨道保留比例；对两侧使用完全
   相同的系数。
5. 阻尼后共同检查有限值、范数、节点进度、径向比和与各自旧轨道的 overlap。任一侧
   失败则两侧都不提交。
6. 双侧初检通过后才临时写回两侧，并按确定顺序执行受影响的 `ORTHY`。post-`ORTHY`
   任一指标失败时恢复整个组快照。
7. 全部通过才原子提交。失败时组级重试计数加一、共同阻尼升级；超过固定上限明确停止。
8. `SCFmpi` 的首轮遍历和 `MAXARR/NSIC` 补充更新都必须调度 group，不能在补充阶段退回
   单轨道更新。

### 3.3 MPI 一致性与审计

- 所有 rank 对候选失败标志做一致归约，由 rank 0 产生唯一组决定并广播；
- trace 至少记录 group id、两个轨道标签、同一前态 id/hash、双侧 raw/post-damp/
  post-`ORTHY` 指标、共同阻尼、fallback、重试次数和最终 commit/rollback；
- 组提交后，各 rank 的轨道摘要必须一致；不一致立即 `MPI_ABORT`，不能继续计算。

## 4. 程序级验证

最小测试必须覆盖：

1. partner 表构造、$s$ 单成员组、重复/未知轨道和缺失伙伴拒绝；
2. 第一侧通过而第二侧失败时，双侧和受 `ORTHY` 影响轨道逐字节恢复；
3. post-`ORTHY` 失败时整个组恢复；
4. 共同阻尼按 `0.5 -> 0.7 -> 0.9` 或冻结策略升级，且不会一侧接受、一侧回退；
5. `METHOD` fallback、非有限候选和重试上限的组级语义；
6. `NSIC` 补充更新仍按组执行；
7. 1/2/4 及生产 rank 数得到相同组决定和可接受的数值一致性；
8. 关闭新开关时与当前已修正 legacy 路径一致；
9. trace 能从记录中重放每次组决定。

## 5. LBL 逐 AS 物理验收

每个 AS 使用同一 CSF、状态集合和 EOL 权重执行：

1. 从上一已接受 AS 生成本层 TF 新轨道；先做固定轨道 CI/RCI，按组态、项、宇称和 $J$
   匹配 NIST，冻结 baseline、目标顺序和绝对容差。
2. 运行 pair transaction。只有直接优化候选可进入成功判定；TF/上一 AS fallback 只用于
   生产恢复。
3. 要求连续两轮同时满足轨道、加权能量和目标身份判据；要求无未解释 fallback、无非
   有限量、目标态主导组态/权重合格。
4. 每个目标间隔同时满足：符号/顺序正确、NIST 绝对误差在预设容差内、绝对误差不大于
   同层 fixed-TF/RCI baseline。禁止看完结果后放宽阈值。
5. 对 Ni I、Ni/Ca-like 和 Cl I 从正确 AS1 anchor 逐层执行；至少重复两次，并保留输入、
   可执行文件 SHA-256、源码提交、编译器/MPI/BLAS、rank/thread 绑定和全部 `GRASP_*`。
6. 任一层失败则停止该优化链；不得把 rejected/fallback wavefunction 作为成功结果传给
   下一层。

## 6. 核极化势：下一物理任务（保留）

核极化是下一阶段任务，但不是当前单侧伙伴错序的既有解释。必须在无核极化的 pair
transaction 基线稳定后，作为独立 Hamiltonian 因素实施，避免把算法修复与物理修正混在
同一次对照中。

按 NP0--NP3 推进：

- **NP0**：标准 `rmcdhf + rci`，冻结无核极化基线；
- **NP1**：在固定 ASF 上计算 $\langle\Psi|V_{NP}|\Psi\rangle$，验证符号和数量级；
- **NP2**：固定轨道 RCI 中加入 E1/E2 一电子径向矩阵元，允许 CI 重混合但不做轨道松弛；
- **NP3**：在 `rmcdhf` 径向势中自洽加入 $V_{NP}$，并在最终 `rci` 保留同一势。

E1 与 E2 先分开；类氢 `1s/2s/2p_{1/2}` 先验证径向积分，再进入中性多电子体系。记录
直接能移、CI 重混合、轨道松弛贡献

$$
\delta E_{relax}=\Delta E_{NP3}-\Delta E_{NP2},
$$

以及核参数、单位换算、核附近网格和活性空间收敛性。核极化的详细物理形式与实现边界见
[核极化势专题](./nuclear-polarization-potential-neutral-atom-grasp.md)。
